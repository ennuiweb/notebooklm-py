# notebooklm-py Docs

This directory contains the long-form documentation for the `notebooklm-py`
client and CLI.

| File | Purpose |
|---|---|
| `cli-reference.md` | CLI commands, options, and common workflows. |
| `python-api.md` | Python API reference and examples. |
| `configuration.md` | Auth, storage, environment variables, and platform notes. |
| `development.md` | Architecture, testing, CI, and contributor workflow. |
| `troubleshooting.md` | Known failures, limitations, and debugging steps. |
| `stability.md` | Public API stability and compatibility guidance. |
| `rpc-reference.md` | Captured NotebookLM RPC method notes. |
| `rpc-development.md` | How to inspect and implement RPC-backed features. |
| `releasing.md` | Release checklist. |
| `examples/` | Runnable example scripts. |

NotebookLM uses undocumented APIs. Treat live generation failures and empty
generation responses as potentially account- or feature-gated until reproduced
across artifact types and accounts.
